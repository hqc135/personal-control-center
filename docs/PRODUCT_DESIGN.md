# 产品与交互设计

状态：拟定，未实现或真机验证。尺寸为 DIP。

## 定位与范围

打开、做一件事、收起的 Windows 托盘工具。普通权限、本地运行、低后台占用。v1 固定声音、电源、临时唤醒、代理、常用入口五模块，以及托盘与独立设置窗口。不扩展天气、AI、清理、监控、亮度或插件市场。

## 面板布局

宽 360，外边距 16，模块间距 12；内容决定高度，上限为当前工作区高度减 24。溢出滚动，标题和设置保持可访问。

## 视觉规范

| 项目 | 初始值 |
|---|---|
| 字体 | 本机 PingFang SC → Microsoft YaHei UI → 系统字体，不分发字体 |
| 字号 | 标题 16、模块标题 14、正文 13、辅助 12；标题中等字重 |
| 间距 | 4 的倍数；控件间 8；模块间 12；外边距 16 |
| 控件 | 最小高度 32，大文本自适应增高；设备入口整行可点 |
| 圆角 | 卡片 12、按钮 8；窗口外圆角由 DWM 决定 |
| 浅色候选 | 背景 #F4F5F7，卡片 #FFFFFF，正文 #20242B，次级 #59616D，强调 #315FC3 |
| 深色候选 | 背景 #202226，卡片 #2A2D32，正文 #F2F3F5，次级 #B6BDC7，强调 #9AB8FF |
| 图标 | 统一许可明确的矢量图标，不混用 emoji |

颜色是 B1 校验对比度前的起点；高对比度用系统色。选中用勾、错误用文字，不能只靠颜色。默认实色，靠间距和轻微背景差异分层，不堆叠阴影。

采用 apple-design 的即时反馈、可打断和空间一致原则；WPF 的材质与动画以原始规格为准，不照搬网页效果。

## 交互合同

| 场景 | 行为 |
|---|---|
| 托盘 | 左键切换面板；右键打开/设置/退出；第二次启动只显示已有面板 |
| 打开 | 先出现可交互框架，再独立刷新模块；旧快照标记待刷新 |
| 关闭 | Esc 或离开本应用时隐藏；设置窗、菜单、展开区不触发误关闭 |
| 音量 | 拖动即时预览，系统确认值独立；失败显示真实值和原因 |
| 输出 | 内联设备列表；兼容门未过时提供系统声音设置 |
| 电源 | 当前选中与待切换目标区分；回读成功才更新勾选 |
| 唤醒 | 30/60 分钟启动或替换剩余时长；活动时显示剩余时间与结束按钮；更改屏幕选项重新确认实际请求 |
| 自定义 | 1–480 分钟，内联校验；Esc 先关闭展开区并返回触发控件 |
| 代理 | 本机端口、指定站点测试分别显示；未配置测试目标时引导设置 |
| 入口 | 截图是截图目录；未绑定显示选择目录；导入程序先确认再执行 |

按下即时反馈、释放执行。开合 120–160 ms、位移最多 6，只动内部透明度和 RenderTransform，不缩放文字。连续开关可反向；系统关闭动画时即时切换。宿主背景与内容效果割裂时默认取消动画。

Tab 顺序遵循视觉顺序，按钮有可访问名称和焦点环，滑块支持方向键，长设备名可查看完整文本。不能安装全局低层鼠标钩子。

## 设置与首次使用

设置独立普通窗口，四组：外观与面板、控制选项、入口与启动、配置与诊断。包含模块显示/排序、主题/动画、电源方案、音频角色、代理目标、快捷键、自启、导入导出与备份。

编辑先进入草稿，保存校验后应用；失败保留草稿与旧值。关闭未保存设置时可保存、放弃、返回。快捷键或自启应用失败逐项报告，不把保存配置当作系统写入成功。

首次启动自动发现声音、电源和下载目录；截图/项目目录和代理程序由用户选择。127.0.0.1:7897 只是可改默认值，不代表已验证本机配置。唤醒、自启、快捷键默认关闭，不设置默认外网探测站点。

B1 集中验收布局、键盘、长文本、浅深色、快速开合；在接入系统控制前收敛一次视觉反馈。

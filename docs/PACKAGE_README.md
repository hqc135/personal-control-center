# Personal Control Center · B4 候选

版本 0.4.0。151 项非交互测试通过，Release 编译无警告/错误；真实系统控制、窗口、性能尚未验收。

需要 Windows 11 x64 build 22621+ 和 .NET 10 Windows Desktop Runtime x64。本包不是自包含包。方便时手动运行 PersonalControlCenter.exe，支持 --show / --tray。托盘右键退出；托盘失败时普通窗口有退出按钮。

声音、电源是真实控制，切方案可能影响亮度/睡眠。默认音频输出切换仍交给系统设置。保持唤醒需点击开始，1–480 分钟，可选屏幕常亮；退出只清除本程序请求，不阻止主动睡眠/合盖。

本机代理默认 127.0.0.1:7897，可见时最多每 10 秒检查一次，500 ms 超时；隐藏取消。手动站点目标默认空，设置并点击后才访问，显式 HTTP 代理、5 秒期限，无凭据/Cookie/重定向/TLS 绕过。

第四轮新增：模块排序/显示、便携配置导入导出、本机备份草稿、可选热键、用户自启。导入不自动执行，保存才应用；便携迁移不携带本机/程序/网页入口、目标、热键与信任。程序入口需本机重新配置并确认。

热键默认关，支持 Ctrl/Alt + 字母或数字，可加 Shift。冲突时本会话保留原键与托盘。用户自启是独立即时按钮，只更新当前用户的本程序 Run 登记，不随导入/普通保存触发；不同位置的同名值拒绝覆盖。移动/删除程序前在原位置关闭自启。

配置：%LOCALAPPDATA%/PersonalControlCenter/config.json；5 份备份。恢复备份只先填入草稿。高版本配置只读。lifecycle.log 仅固定退出结果，2 MiB 轮换，最多 5 份。

游戏期间无需运行。实际睡眠恢复、网络、热键、自启、Explorer、DPI/焦点和性能仍待验收。未签名自用候选，许可证待确认，无个人配置/字体/SDK。随包提供配置 schema、迁移恢复说明和音频兼容说明。

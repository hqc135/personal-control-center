# Personal Control Center · B6 候选

版本 0.6.1。172 项非交互测试通过，Release 编译无警告/错误。**假数据演示界面已验收；真实系统控制和性能未验收，不是正式发布版。**

本轮交付 framework-dependent 模式，需要 Windows 11 x64 build 22621+ 和 .NET 10 Windows Desktop Runtime x64。自包含运行时下载因 TLS 失败受阻，未生成自包含包。准确模式、Git 提交和文件哈希见 RELEASE.json。

方便时手动运行 PersonalControlCenter.exe，支持 --show / --tray。托盘右键退出；托盘失败时普通窗口可退出。游戏期间无需运行。

声音/静音、电源方案是真实操作，切方案可能影响亮度/睡眠。原生默认音频输出切换仍禁用，通过系统声音设置完成。保持唤醒须点击开始，1–480 分钟，可选屏幕常亮，不阻止主动睡眠，不清除其他应用请求，不恢复上次会话。

本机代理默认 127.0.0.1:7897，可见时最多每 10 秒检测一次、500 ms 超时。外部目标默认空，配置并点击才发显式代理请求，5 秒期限，无 Cookie/凭据/自动重定向/TLS 绕过。隐藏取消检测。

配置导入/备份先载入草稿，保存才应用；模块可排序/隐藏。便携迁移不携带本机/程序/网页入口、测试目标、快捷键和信任。程序入口须本机核对确认。热键默认关，冲突保留原键/托盘。用户自启为独立即时按钮，不随导入/普通保存启用。

第六轮补充配置冲突检测、重新载入、保存后清理警告和关闭后的异步结果隔离。已有退出日志包含关联 ID/耗时。日志不含个人路径、网址或响应正文，2 MiB 轮换，最多 5 份。

配置位于 %LOCALAPPDATA%/PersonalControlCenter，5 份备份。移动或删除启用过自启的程序前，先在原位置关闭自启；配置独立保留。

未签名自用候选，项目许可证待定，在线漏洞审计未完成。DEPENDENCIES.json 是构建/测试依赖的离线盘点，不能视为漏洞扫描。真实待验收项目见 RELEASE_CHECKLIST.md。

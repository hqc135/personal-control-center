# 分批执行与验收计划

状态：B6 配置可靠性补强与非交互验收完成，172 项测试通过。真实窗口/系统控制、自包含交付与正式发布门仍待完成；见 acceptance/B6.md。

## 执行方式

建议首轮范围 B0+B1；以后按批次扩展。用户确定范围后，同批内编码、构建、假服务测试、修复、打候选包连续完成，无需每步确认。每批结束提供可审阅结果与验收单；上一批关键门未过，不把依赖它的后续工作标成完成。可独立进行的文档/假服务工作仍可继续。

编写系统控制代码与在用户机器上实际触发控制分开。真机写入、机器级安装、自启写入、Explorer 重启等先列具体目标、操作、原值、恢复方法与影响，由用户执行或给出明确范围；不重复索取已有具体授权。第五轮继续仅代码/非交互测试和归档，不实施这些真机操作。

## 每批统一完成定义

1. 源码符合层次，范围内功能和错误路径齐备。
2. 记录实际 restore/build/test 命令、退出码与结果；默认测试只用假服务，不改变宿主。
3. 发布候选包可启动，标明批次、构建标识、演示/真实模式、已知限制。
4. 验收单关联源码 commit；未提交时记录源码归档 SHA256。包本身另记 SHA256。
5. 标注代码状态与验收状态，汇总遗留问题、阻断项和下一步，不用“做完了”混同二者。

首轮生成锁文件后才启用 locked-mode 恢复。Release build/test 与对应 publish 的目标框架、RID 和恢复资产必须一致；命令在 B0 创建项目后验证，不照抄未适配的命令制造可复现假象。

## 验收分层

| 层次 | 谁执行 | 主要证据 |
|---|---|---|
| 自动验证 | 开发执行者 | 假服务测试、状态机、竞态、配置原子性、错误恢复 |
| 原生只读 | 开发执行者 | 环境、真实枚举、能力状态、初始化释放；不触发系统写入 |
| 真机功能 | 用户或获得具体授权的执行者 | 原值、动作、回读、外部状态核对、恢复结果 |
| 主观体验 | 用户 | 布局、动效、字体、响应和是否愿意常驻 |
| 发布复核 | 单独一轮检查 | 对照源码/包/证据复核，避免只引用开发进度 |

结果只用通过、失败、未验证、不适用；不适用必须说明原因。批次结论用可验收、有条件候选、不可验收。缺设备/显示器的用例保留未验证；已知真写错误不能用“有条件”放行。

## 关键用例与性能

沿用原文 UI/AU/PW/AW/PR/TR/CF/PF 编号。每条执行时复制具体步骤并关联证据，不只写编号：

- UI：100/125/约135/150/200% DPI、多屏负坐标、拔屏、长文本、键盘/读屏、系统动画关闭和高对比度。
- AU/PW：系统面板和应用交替修改；设备拔出；音量连续拖动；角色部分失败；电源方案被删除。
- AW：启动、续期、取消、到期、时间前后拨、跨睡眠、退出，以及另一程序仍持有唤醒的情况。
- PR：端口拒绝/超时、端口被其他程序占用、HTTP 403、TLS 失败、目标超时。说明实际 API 能区分的错误，不猜测代理内部状态。
- CF/TR：坏配置、高版本、导入程序信任绕过、保存中断、快捷键冲突、重复启动、托盘创建失败、Explorer 恢复。

| 性能项 | 测量与起始门槛 |
|---|---|
| 热打开 | 预热后 30 次，触发到首个可交互布局，p95 ≤150 ms，保存原始样本 |
| 隐藏 CPU | 稳定 60 秒，进程 CPU 时间增量 ≤0.5 秒；另观察隐藏 10 分钟 |
| 内存 | 私有字节 ≤100 MiB 起始预算；工作集独立记录 |
| 开合稳定性 | 500 次，记录前/中/后私有字节、句柄、线程、订阅数；不能只看最后一个点 |
| 网络与超时 | 隐藏无远端探测；本机超时 ≤500 ms，手动站点总超时 ≤5 秒 |
| 刷新率 | 60/120/240 Hz 分别记录实测环境；未具备环境不声称通过 |

出现写错设备、唤醒请求不释放、配置丢失、多实例、面板无法关闭、隐藏高频消耗，立即阻断发布。默认输出切换与材质可降级；核心正确性问题必须修复。

## 变更与回退

用户在第四轮明确要求不保留旧包，B1–B3 的六个 ZIP 已删除；历史验收证据仍保留，旧发布/暂存目录因递归删除被自动审批拒绝而暂留。配置备份仍保留，这是运行数据保护而非旧程序包。配置版本升级前验证备份与恢复，旧版本不得强行覆盖新 schema。回退应用不等于回退系统状态；真机测试恢复仅当当前值仍等于测试设置值，检测到外部改动就报告并停止自动恢复。

新增功能先注明替换哪一项或进入 v1.1；重大架构变更追加 ADR。正式名称、图标、强调色、路径、快捷键不阻塞 B0；默认设备切换与材质保持条件能力。

## 交付变化

- AwakeSession：1–480 分钟、续期、可选屏幕常亮；UTC 截止与单调预算任一到期即结束；恢复时先判过期，不恢复上次进程会话。
- AwakeService：固定后台线程执行所有原生申请/清除；活动时每秒检查截止，关闭时阻塞等命令；退出清除并等待线程结束。失败申请不进入 Active，释放/恢复未确认进入 ReleaseUnconfirmed，禁止直接续期，允许显式重试结束。不会声明其他应用请求已清除。
- Proxy：仅 loopback IP 字面量；可见时本机 TCP 检查至多每 10 秒，500 ms 超时，隐藏取消。默认没有外部目标或自动外网请求。
- 手动目标测试：显式 HTTP 代理、5 秒取消期限、只读响应头，HTTP 403/302/500 仍显示响应；407 或代理隧道错误、TLS 失败和无法定位的连接失败分别显示。无 Cookie、凭据、重定向、TLS 绕过、响应正文日志。
- 设置页保存代理地址/端口/手动目标，绑定现有 EXE 入口；EXE 启动复用本机信任机制。
- 托盘恢复只重新注册图标及版本，不重建业务服务；失败时普通窗口保留任务栏与退出按钮。
- 退出先停止 UI/取消探测，然后优先释放唤醒，再有界等待协调器、音频、电源。失败/超时不阻断后续释放，结果写入固定字段日志。
- 隐藏面板不刷新唤醒 UI；必要的到期检查仍在请求拥有线程执行。

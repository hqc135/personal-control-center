## 已实现

- 音频：Core Audio 真实端点枚举、默认多媒体/通信设备识别、主音量/静音读取与写入；固定 MTA worker，端点/音量事件订阅及释放。
- 命令：最多一个执行和一个等待请求；音量最新值合并、约 30 次/秒上限；拖动绑定端点；执行前检查存在性；逐次回读。取消后不能假装原生写入已撤销。
- 状态：模块独立错误、刷新/过期/pending/结果待确认；查询 epoch/query ID 防止旧读取覆盖新状态；正式模式没有假服务回退。
- 电源：按真实 GUID 枚举现有方案、友好名称、当前方案和 AC/DC；串行激活与回读。监听电源通知；仅面板可见时每 5 秒低频补读，覆盖同一 personality 内切方案可能没有通知的情况；隐藏后停止。
- 入口：KnownFolder 下载目录、本机目录、EXE+参数数组、HTTP/HTTPS；设置中新增/修改/移除；导入程序默认未信任，独立本机记录核对精确目标/参数/工作目录；不将任意 shell 字符串拼接执行。
- 发行：PersonalControlCenter.exe，真实模式；配置目录独立于 B1 演示目录；B1 ZIP 保留。

默认输出切换仍回退系统声音设置。唤醒与代理明确显示未接入，不显示演示成功。

## 限制与后续门

本包可以操作真实系统，但尚不能称为真机验收通过。请勿将自动测试结果泛化为原生 COM ABI、设备驱动、焦点、托盘或电源通知已通过验证。

- 保持唤醒/代理在 B3 接入，默认输出兼容切换在 B4；无自启/快捷键写入。
- 同一电源 personality 的外部变化最多可能延迟一个可见补读周期；不是隐藏后台轮询。
- 原生接口挂起无法由 CancellationToken 强制撤销，退出采用有界等待；需要真机故障/退出场景验证。
- 当前框架依赖包需要本机 .NET 10 Windows Desktop Runtime，不是自包含包；没有重新下载运行时。
- 本轮复用已锁定依赖，增加 App 测试引用；恢复时关闭联网 NuGet audit 以免游戏期间额外网络检查，不声称完成依赖漏洞审计。最终发布审计仍在 B5。

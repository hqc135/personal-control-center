# 0.6.2 窗口操作与电源方案说明

用户反馈电源方案无法切换、窗口不能移动和缩放。

只读 `powercfg /list` 确认本机只有平衡方案（381b4222-f694-41f0-9685-ff5bb260df2e），不是应用漏读。改为禁止重复选择当前方案，提示系统仅一个方案，并提供固定 ms-settings:powersleep 入口。不创建、删除或恢复电源方案，不自动提权。电源模式的可用项由 Windows 决定。

窗口使用 WindowChrome 原生标题拖动和边缘缩放，自定义右下角拖动手柄。默认 380×700 DIP，最小 340×360 DIP；内容区滚动。用户移动/缩放后，本会话隐藏与重开保留几何位置；监视器工作区按窗口所在屏幕计算。退出重启不持久化位置。移除状态文案中的“第五轮”。

自动测试 174 项；新增当前/未知方案不可执行与已存在替代方案可执行、固定电源设置 URI 测试。UI 工具验证 WM_NCHITTEST：标题 HTCAPTION、边缘 HTLEFT、设置按钮 HTCLIENT；程序化移动/缩放后发送结束移动消息，再隐藏重开，检查几何位置不丢失。沿用浅色/深色及设置页断言。

证据：artifacts/evidence/UI-0.6.2/result.txt 与 PNG、artifacts/evidence/B6/unit-tests.trx、delivery-check.json。截图检查了缩小面板和滚动内容。没有注入全局鼠标，没有切换真实电源方案；上述命中与几何测试不等于全屏幕组合的手动拖拽验收。仅查看系统方案列表，未启动生产 App、打开真实系统设置或停止用户正在运行的旧版本。

官方设置入口依据：https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings

本版提供自包含 win-x64 ZIP，包内 RELEASE.json 与 Git 提交关联。性能、多屏/DPI 全矩阵和系统集成仍待验收。

# 0.8.1 直接服务调用

删除麦克风、输出和亮度三个写入路径的转发层。界面直接调用实际系统服务；明确 App 对亮度服务的创建/释放责任；系统读取和写入共用同一实例。界面通用执行辅助方法改为私有。详情见 [系统调用说明](../SYSTEM_CALLS.md)。

新增假服务回归验证原目标 ID、操作后刷新、系统错误提示、失败不重复写入及释放后不再写入。统一运行现有测试；结果在 artifacts/evidence/B6。假数据界面流程沿用 UiAcceptance，验证麦克风、亮度、输出、媒体及场景恢复，证据在 artifacts/evidence/DIRECT-0.8.1。

本轮不操作真实音量、麦克风、电源、亮度、输出或自启；不将假服务验收当作硬件写入验收。0.7.1 的只读实测记录仍按原范围引用。GitHub Release 尚未发布。

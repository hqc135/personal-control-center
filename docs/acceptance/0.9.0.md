# 0.9.0 日常使用与发布验收

| Before | After | Why |
| --- | --- | --- |
| 单设备仍显示输出选择器，单方案仍列出不可点的当前方案 | 只显示当前状态，切换列表仅在有多个目标时出现 | 减少无效操作 |
| 亮度只有滑块 | 显示百分比，并标明调整后点应用 | 区分待应用值与真实写入 |
| 长设备名和媒体标题撑高卡片 | 单行截断，提示框可读完整名称 | 保持卡片高度稳定 |
| 连接信息、媒体应用标识一直展开 | 详情按需展开 | 主要控制更容易找到 |
| README 只列本地产物 | GitHub Release ZIP 直接下载 | 用户不需要构建源码 |

代码保留无媒体会话时隐藏卡片；亮度区区分未读取、读取失败与未发现支持的屏幕，不把未知硬件原因写成确定故障。没有自动创建电源方案或修改硬件状态。

假服务 UI 验收包括原音频/场景流程、亮度百分比、单方案/单输出、空媒体卡片、无麦克风/亮度提示，截图与结果在 artifacts/evidence/DAILY-0.9.0。199 项自动测试和包清单在 artifacts/evidence/B6。小窗口、浅深色沿用集中 UI 流程；没有执行真实系统写入或自动在线更新。

发布流程：创建 draft → 上传运行 ZIP 与 SHA256 → 对比 GitHub asset digest 与本地哈希 → 发布为预发布版。用户数据不随 ZIP 分发；程序与配置目录分离，主题和收藏沿用；更新回退步骤见 [使用说明](../USER_GUIDE.md)。旧配置的备份与恢复需在应用退出后操作，不宣称还原 Windows 系统状态。

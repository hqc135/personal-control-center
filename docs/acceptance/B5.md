# B5 第五轮验收

日期：2026-09-26。版本 0.5.0。结论：**代码与非交互发布检查完成；框架依赖候选可交付，自包含与正式发布验收未完成。**

用户要求用 Git 管理代码并继续第五轮。创建 codex/b5-release，提交 B4 基线 744b804；B5 独立提交。无远端推送。仍遵守游戏期间限制，未启动应用、UI 工具、探针或真实宿主写操作。

## 改动

- 唤醒线程异常退出：关闭队列并拒绝排队/未来任务，不再留下永远等待的命令；资源释放同步处理并发 Dispose。
- 显示设置/DPI 变化：重新计算面板工作区与高度限制。字体采用 WPF 回退列表，避免每次打开设置枚举所有系统字体。
- 退出日志：关联 ID、耗时、固定结果和可选 HRESULT，不记录异常文本/用户路径/URL/响应；日志写入失败不阻止后续清理。
- 发布：只打包当前干净 Git 提交及匹配构建收据；源码取跟踪文件，逐文件 SHA256，包内 RELEASE.json，源码提交文件。
- 依赖：12 个锁定构建/测试包的本地许可与哈希清单；运行包无这些测试依赖。
- 提供固定版本自包含运行时准备脚本、显式 self-contained 构建/打包路径；不绕过证书校验，不裁剪 WPF。

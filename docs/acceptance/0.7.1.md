# 0.7.1 真机只读验收与修复

日期：2026-10-03。用户授权只读探测、打开界面；没有调整音量、静音、麦克风、亮度、输出设备、电源方案、保持唤醒、自启或代理。

## 实际发现与修复

- WMI 亮度第一次读取正常，同一进程后续读取属性返回 80004005。改为通过 Properties_.Item(name).Value 读取命名属性，保留明确的错误提示与 COM 对象释放。同一进程连续三次查询均发现一个内置屏幕；未通过反复重启掩盖问题。
- 网络状态原先列出大量过滤器接口。只保留拥有有效地址的已连接接口，优先显示带网关的连接，最多展示两个名称并汇总其余数量。此机显示 WLAN 和另外两个本地连接，不将链路连通等同于互联网可用。
- WPF 退出时可能重复处理已销毁的窗口，导致 HWND 为零的异常。退出改为幂等，移除消息钩子前检查句柄。修复版两次通过托盘正常退出，服务收尾日志均完成；最终退出后的近期 Application 日志未发现该应用的新 1026 崩溃记录。

## 已验证

- Realtek 输出初次读到音量 26%，最终只读复核为约 22%、未静音；此期间未调用音量写入，也未恢复或覆盖外部变化。Intel 麦克风未静音。
- 电池 100%、已接电源；只发现一个“平衡”电源方案。因此本机没有第二个现有方案可供切换，这次也未创建方案。
- 内置屏幕亮度 55%，连续读取无错误。实际面板初次滑块读回 55，手动刷新后设备项仍为 55；截图中滑块正常渲染。
- 蓝牙已开启；没有可用于验证播放控制的媒体会话。
- 主面板、固定、全部功能、滚动、设备刷新及托盘退出已在真实服务下操作。真实数据截图使用此机当前缩放比例，未改系统 DPI。

# 0.6.3 主面板卡片改版

保留 WPF 与现有系统服务，重新组织主面板。默认 420×700，声音、代理和常用入口为横卡，相邻的电源与唤醒卡在空间充足时并排。窄窗口自动单列；模块排序与隐藏仍由原配置控制。详情折叠，正常的重复读取提示隐藏，异常反馈保留。

使用有授权的独立假数据工具验收，不启动生产应用、不切换真实系统控制、不停止现有进程。

- 验证 420px 并排、340px 单列，以及 340×360 展开详情后能够滚动到最后一张卡。
- 浅色、深色截图人工检查；标题、边缘、设置按钮原生命中测试通过，重新打开保留本次窗口几何。
- 设置窗口滚动、缩小、焦点、备份下拉回归；假音频静音与假唤醒命令执行。
- 构建与单元测试结果见 artifacts/evidence/B6；UI 结果与截图见 artifacts/evidence/UI-0.6.3。

不宣称已验收真实音频、电源切换、所有显示缩放比例或多显示器组合。视觉采用分层实色表面，没有新增模糊特效、后台轮询或在线依赖。

# 配色与 CSS 主题

0.8.0 起，在设置 → 外观中选择石墨、海蓝、薄荷、薰衣草、玫瑰或暖沙。配色与明暗模式独立：每套配色均可选浅色、深色、跟随 Windows。

点“预览配色”只改变当前设置窗口；点“保存设置”后应用到主面板和其他窗口。取消不会更改原主题。“恢复默认外观”把草稿恢复为石墨、跟随系统、无自定义 CSS；仍需保存才永久生效。动画设置单独保留。

展开“自定义 CSS 主题”可编辑文本、填入示例、导入或导出 .css 文件。“清空自定义”会回到所选基础配色。导入后为草稿，不会自动覆盖配置；导出只包含 CSS 变量，基础配色和明暗选择通过便携配置一并迁移。

## 支持的 CSS

这是 WPF 原生界面的 CSS 主题变量子集，不是浏览器引擎。不支持普通选择器、布局规则、字体加载、动画、@import、url() 或脚本。未知变量及无效值会报错，不静默忽略；预览出错保留上次有效结果，保存出错保留原配置。

```css
/* 未指定的变量继承所选配色。后出现的适用声明覆盖前面。 */
:root {
  --accent: #7356BF;
  --card-radius: 18px;
  --card-padding: 16px;
  --control-radius: 10px;
}
[data-theme="dark"] {
  --accent: #C5B4FF;
}
```

支持 :root、[data-theme="light"]、[data-theme="dark"] 三种块。建议先写 :root，再写明暗覆盖。即使块当前不生效，也会检查它的语法。允许 /* 注释 */，文件总长度最多 16,384 字符。导入使用 UTF-8 文本（也识别常见 Unicode BOM）。

| 变量 | 作用 / 范围 |
| --- | --- |
| --background | 窗口背景 |
| --surface | 卡片、输入框等表面 |
| --text | 正文 |
| --secondary | 次要文字 |
| --accent | 强调色、图标和滑块 |
| --accent-surface | 选中或强调背景 |
| --border | 边线 |
| --hover | 悬停背景 |
| --card-radius | 卡片圆角，0–32px 整数 |
| --card-padding | 卡片内边距，8–32px 整数 |
| --control-radius | 按钮圆角，0–20px 整数 |

颜色只接受不透明 #RGB 或 #RRGGBB；这里 px 映射到 WPF 的设备无关单位，会随系统 DPI 缩放。窗口原生边框、系统菜单及第三方控件不承诺由这些变量控制。Windows 高对比度启用时，系统颜色优先于预设和 CSS。自定义颜色的可读性由作者检查，不自动保证对比度。

## 保存、恢复与维护

配色存于 config.json 的 appearance.palette，自定义文本存于 appearance.customCss。导入 CSS 后不依赖原文件位置，没有后台文件监听。原有配置不含这些字段时使用石墨和空 CSS；仍沿用既有原子保存、备份和外部修改冲突检测。

手改配置导致 CSS 无效时走现有配置恢复/只读保护流程，不会执行 CSS 或加载远程内容。先备份文件，再将 customCss 改为空字符串、palette 改为 graphite，可恢复默认主题字段。

实现边界：Core/AppearanceStyles 负责变量解析和预设，App/ThemeManager 将已验证变量映射为 WPF 动态资源。新增变量须同步解析白名单、资源映射、文档及解析边界测试。无需引入 WebView 或浏览器运行时。

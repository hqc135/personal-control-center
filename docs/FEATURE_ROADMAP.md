# 控制中心：功能清单 · 0.7.0

2026-10-03 更新：按用户要求集中实现原 A/B/C 功能后统一验收。以下“已实现”表示代码与假数据流程完成，不代表真实硬件兼容矩阵已验收。

| 功能 | 实现与入口 | 能力边界 |
| --- | --- | --- |
| 入口搜索 | 常用入口输入过滤，↓ 选择、Enter 打开、Esc 清空 | 沿用程序信任校验 |
| 窗口记忆 | 移动缩放结束保存，下次启动恢复 | 显示器变化时限制尺寸并移回可见工作区 |
| 快捷设置 | 显示、蓝牙、网络、混音器、存储、麦克风权限 | 打开 Windows 设置 |
| 收藏布局 | 收藏/全部功能、编辑收藏 | 收藏保存在 features.json；原模块排序继续生效 |
| 电池 | 百分比、供电和充电状态 | 无电池自动隐藏，未知值不填假数字 |
| 媒体 | 曲目、作者、播放状态、多播放器、上一首/暂停/下一首 | 需要系统媒体会话，无会话收起 |
| 麦克风 | 默认输入设备静音、回读 | 目标变化时拒绝写入；无权限则禁用 |
| 亮度 | 每屏滑杆与“应用” | 内屏 WMI、外屏 DDC/CI；仅显示可读屏幕，不支持时提供显示设置 |
| 输出切换 | 声音设备列表选择后直接切换 | 兼容接口；切系统与媒体角色、保留通话角色；失败读回并有条件恢复 |
| 网络/蓝牙 | 连接接口与蓝牙状态 | 只读；不自动连接，链路连通不代表互联网可用 |
| 自定义场景 | 保存/删除、预览、执行、恢复 | 音量、静音、唤醒、电源；空项不改；失败停止后续步骤，恢复保留后来手动变化 |
| 更新/回退 | 手动检查、下载、SHA256、本地导入、版本目录 | 私有仓库临时 token；并排解压，手动退出旧版再运行新版；不自动执行下载文件 |

默认 460×720 DIP，固定标题与收藏/全部功能导航，内容滚动。短模块双列，窄窗口单列；亮度、媒体、连接和工具使用整行。硬件状态按需刷新，不增加定时后台轮询。

Core 保存能力快照、配置验证与场景恢复逻辑；Windows 封装系统接口、配置和更新包；App 负责布局与交互。features.json 保存几何、收藏和场景，含版本校验、备份和外部修改检测，不保存 token 或活动唤醒请求。验收见 [0.7.0](acceptance/0.7.0.md)。

## 本轮布局

默认 440×620 DIP；正常情况下首页可见五个模块。保持用户模块顺序，相邻半宽卡配对；窄于配对阈值时改成单列。标题固定，内容区滚动。

```text
控制中心                    刷新 固定 设置
真实系统状态
┌────────────────────────────────────┐
│ 声音                       设备 ›  │
│ 输出设备                           │
│ 静音  ━━━━━━━━━━━━━━━━        60%  │
└────────────────────────────────────┘
┌─────────────────┐ ┌────────────────┐
│ 电源            │ │ 保持唤醒       │
│ 当前方案/供电   │ │ 剩余时间       │
│ › 方案与设置    │ │ 30 分钟 / 结束 │
└─────────────────┘ └────────────────┘
┌─────────────────┐ ┌────────────────┐
│ 代理连接        │ │ 常用入口  编辑 │
│ 真实检测状态    │ │ 收藏应用/目录  │
│ › 详情与测试    │ │                │
└─────────────────┘ └────────────────┘
操作反馈，仅在需要时出现
```

后续增加功能时，不继续向首页堆卡片：新增“控制 / 全部功能”切换，首页保留用户收藏的 4–6 个模块；搜索与低频入口进入“全部功能”。设置仍为独立窗口。首页不放不可用占位按钮。

## 执行与验收顺序

1. 本轮：双列布局、固定面板、浅深色/窄窗口假数据验收。
2. 下一轮 A：搜索和快捷设置入口；先覆盖输入/键盘/失败反馈，再加入位置持久化。
3. B 批按每次一个系统服务推进：假实现 → 服务单测 → UI → 单独真机验收。亮度、麦克风、设备切换不一次混改。
4. C 批仅在 A/B 稳定后安排，场景不能以“游戏优化”为名批量改系统。

每批交付：代码与说明、自动测试证据、假数据截图、可运行包、未验收项。只有验证过的能力显示为直接控制；其余显示真实入口或暂不展示。

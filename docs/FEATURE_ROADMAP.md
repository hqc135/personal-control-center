# 控制中心：功能清单与布局路线

2026-10-03。本文扩展早期 PRODUCT_DESIGN 的五模块范围；下面的待开发项是产品计划，不代表已经接入。保留现有 WPF 服务边界，以日常高频、离线、低后台开销为标准。

## 当前可用

| 区域 | 功能 | 首页呈现 |
| --- | --- | --- |
| 声音 | 主音量、静音、输出设备列表、系统声音设置入口 | 横向主卡；设备详情展开 |
| 电源 | 实际电源方案、供电状态、方案切换、系统设置入口 | 半宽卡；不伪造系统未提供的方案 |
| 保持唤醒 | 30/60 分钟、自定义时长、停止、可选屏幕常亮 | 半宽卡；剩余时间作为状态 |
| 代理 | 本地端口检测、指定目标测试、绑定程序启动 | 半宽卡；端口可达不等于互联网可用 |
| 常用入口 | 应用、文件夹、网页、下载目录 | 半宽卡；可编辑 |
| 面板 | 拖动、缩放、主题、模块排序隐藏、快捷键 | 顶栏和设置 |
| 本轮新增 | 固定面板，失焦不收起；再次点击解除 | 顶栏“固定”；本次进程有效，Esc/托盘仍可收起 |

## 扩展功能 list

| 批次 | 功能 | 使用价值与验收 | 成本/边界 |
| --- | --- | --- | --- |
| A | 常用入口搜索与键盘启动 | 输入即过滤；方向键选择、Enter 启动、Esc 清空 | 低；复用已确认的入口，不能绕过应用信任 |
| A | 面板尺寸与位置记忆 | 重启保留；显示器移除后回到可见工作区 | 中；覆盖 DPI、工作区与配置迁移 |
| A | 快捷设置入口组 | 显示、蓝牙、网络、声音混音器、存储设置 | 低；明确标为“打开设置”，不能伪装成开关 |
| A | 收藏布局 | 常用控制留首页，其余放“全部功能” | 中；隐藏后仍可恢复、键盘能到达 |
| B | 电池百分比与充电状态 | 笔记本显示，台式机自动隐藏 | 中；未知状态和陈旧值必须可辨认 |
| B | 媒体控制 | 当前曲目、播放暂停、上一首下一首 | 中；多播放器选择、无会话时收起；先验证兼容性 |
| B | 麦克风静音 | 显示目标输入设备和真实静音状态 | 中高；热插拔与状态回读；不能只改图标 |
| B | 亮度 | 内屏滑杆；外屏按支持能力提供 | 高；先做硬件能力探测，不支持时提供设置入口 |
| B | 输出设备直接切换 | 耳机/扬声器一步切换，并读回确认 | 高；先选定可维护实现，失败可回退系统设置 |
| C | 蓝牙与网络状态 | 当前连接、状态、设置入口 | 中高；先只读，再评估直接开关，不能自动连接 |
| C | 自定义场景 | 用户明确配置“工作/游戏/观影”操作组合 | 高；逐项预览、部分失败说明、原状态恢复；默认不动电源和网络 |
| C | 更新提示与回滚 | 手动检查，下载校验，保留可回退版本 | 中高；私人仓库访问、离线、未签名情况需设计 |

不纳入当前路线：天气新闻、常驻 CPU/GPU 仪表盘、清理加速、一键优化、插件市场。它们会增加后台开销或分散主面板用途。

## 本轮布局

默认 440×620 DIP；正常情况下首页可见五个模块。保持用户模块顺序，相邻半宽卡配对；窄于配对阈值时改成单列。标题固定，内容区滚动。

```text
控制中心                    刷新 固定 设置
真实系统状态
┌────────────────────────────────────┐
│ 声音                       设备 ›  │
│ 输出设备                           │
│ 静音  ━━━━━━━━━━━━━━━━        60%  │
└────────────────────────────────────┘
┌─────────────────┐ ┌────────────────┐
│ 电源            │ │ 保持唤醒       │
│ 当前方案/供电   │ │ 剩余时间       │
│ › 方案与设置    │ │ 30 分钟 / 结束 │
└─────────────────┘ └────────────────┘
┌─────────────────┐ ┌────────────────┐
│ 代理连接        │ │ 常用入口  编辑 │
│ 真实检测状态    │ │ 收藏应用/目录  │
│ › 详情与测试    │ │                │
└─────────────────┘ └────────────────┘
操作反馈，仅在需要时出现
```

后续增加功能时，不继续向首页堆卡片：新增“控制 / 全部功能”切换，首页保留用户收藏的 4–6 个模块；搜索与低频入口进入“全部功能”。设置仍为独立窗口。首页不放不可用占位按钮。

## 执行与验收顺序

1. 本轮：双列布局、固定面板、浅深色/窄窗口假数据验收。
2. 下一轮 A：搜索和快捷设置入口；先覆盖输入/键盘/失败反馈，再加入位置持久化。
3. B 批按每次一个系统服务推进：假实现 → 服务单测 → UI → 单独真机验收。亮度、麦克风、设备切换不一次混改。
4. C 批仅在 A/B 稳定后安排，场景不能以“游戏优化”为名批量改系统。

每批交付：代码与说明、自动测试证据、假数据截图、可运行包、未验收项。只有验证过的能力显示为直接控制；其余显示真实入口或暂不展示。

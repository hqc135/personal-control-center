# 使用说明

适用版本：0.8.0 候选。Windows 11 x64，内部版本 22621 或更高；self-contained 免安装 ZIP 已包含 .NET 10 Windows Desktop Runtime x64，普通使用无需另外安装 .NET 或 SDK。

主面板中的电源与保持唤醒卡在宽窗口并排，在窄窗口自动上下排列。点“方案与设置”“时长与选项”“连接详情与测试”可展开详细操作；展开后可滚动浏览。拖动顶部移动窗口，拖动边缘调整大小。声音卡上的“设备”展开输出设备信息。

## 获取与启动

本地候选为 PersonalControlCenter-0.8.0-win-x64.zip；GitHub 已发布包见 [Release](https://github.com/hqc135/personal-control-center/releases)，尚未发布的本地候选不一定在那里。私有仓库需登录有权限的 GitHub 账号。不要下载 Source code，那是开发源码。下载后：

1. 将整个 ZIP 解压到固定目录，保留所有 DLL、runtimeconfig.json 和 Assets，不能只复制 EXE。
2. 双击 PersonalControlCenter.exe，默认显示面板；无需管理员权限。
3. 点击通知区域中的图标显示/隐藏面板。右键托盘图标可打开设置或退出；若未看到图标，检查通知区域折叠菜单。
4. 可用 `PersonalControlCenter.exe --tray` 启动后仅驻留托盘，或 `--show` 显示面板。一次只用一个参数。托盘不可用时会显示可退出的普通窗口。

拖动面板顶部标题可移动；拖动边缘或右下角可缩放（最小 340×360 DIP）。内容超出时滚动查看。位置与大小跨重启保存；全部功能中的“重置窗口位置”恢复默认布局。

隐藏面板不等于退出。再次运行会尝试唤起已有实例。

## 日常操作

| 模块 | 操作与边界 |
|---|---|
| 声音 | 调音量与静音；展开设备列表，选择后点击直接切换。只改媒体与系统默认角色，保留通话角色；失败时使用系统声音设置。 |
| 电源 | 点击其他方案切换整个 Windows 电源方案，当前方案不重复执行。系统只有一个方案时不能切换到不存在的方案；点击“打开系统电源设置”可调整系统提供的电源模式。电源方案与电源模式不是同一个列表，不自动创建/恢复系统方案。 |
| 保持唤醒 | 点击 30 分钟、1 小时或输入 1–480 分钟开始；可选本次保持屏幕常亮。结束按钮释放本程序请求，不清除其他应用请求。不阻止主动睡眠或合盖，不恢复上次会话。 |
| 代理 | 默认检查本机 127.0.0.1:7897。可见时最多每 10 秒检查一次，端口可达不代表外网可用。外部目标默认空，配置后手动点击测试才请求指定目标。 |
| 常用入口 | 添加目录、网页或程序。程序入口需核对路径、工作目录及参数并确认；确认不会立即启动程序。 |

## 设置

“收藏”显示常用卡片；“编辑收藏”即时保存选择，“全部功能”可找回未收藏的功能。媒体无会话、电池不存在时自动收起。常用入口支持输入搜索、↓ 选择、Enter 打开、Esc 清空；程序启动继续检查信任。

亮度先调滑杆、再点“应用”；麦克风操作后回读状态。媒体按播放器分组，按钮仅在该播放器允许时启用。网络显示链路而非外网连通保证，蓝牙提供状态和系统设置入口。设备数据按打开/手动刷新更新。

“场景”允许选择音量、静音、唤醒和电源，空项不改。先保存或编辑，点击“预览操作”后执行；执行失败停止后续步骤。“恢复上次场景”仅恢复仍与场景目标一致的项目，不覆盖后来手动调整的值。恢复记录只在本次程序运行有效。

“更新与回退”手动查询发布包；私有仓库可填临时 GitHub token（不落盘），也可选择本地 ZIP 并填写发布者 SHA256。校验后并排解压，旧版本不删除。退出旧程序后从目标目录运行 EXE；切回旧目录即回退，配置兼容性另行确认。

- 外观支持跟随系统、浅色、深色；可关闭轻微开合动画。
- 模块可调整顺序和隐藏。隐藏“保持唤醒”不会停止已开始的请求，需先结束或重新显示模块。
- 全局快捷键默认关闭；可填写 `Ctrl+Alt+P`，保存后尝试注册。冲突不影响托盘入口。
- 普通设置需要点击固定在底部的“保存设置”才应用；取消放弃草稿。
- **用户自启按钮立即生效**，不受普通保存/取消控制。默认不启用，配置导入也不会自动启用。
- “打开代理”须先添加程序入口、确认其目标与参数，再绑定入口。

## 配置、备份与迁移

运行数据位于 `%LOCALAPPDATA%/PersonalControlCenter`：

| 路径 | 用途 |
|---|---|
| config.json | 当前配置 |
| features.json / features.json.bak | 窗口几何、收藏、场景及上一份备份；跨机器迁移时可删除几何字段 |
| versions/ | 校验后并排解压的版本，不自动执行或删除 |
| backups/config-数字.json | 最近 5 份配置备份；清理失败时可能暂时超过 5 份 |
| trusted-shortcuts.json | 本机程序入口确认记录，不用于便携迁移 |
| lifecycle.log 及轮换文件 | 退出诊断，单份约 2 MiB，最多 5 份 |
| .config-write.lock | 保存互斥文件；存在空文件不代表仍被锁定 |

导入配置和读取备份先载入草稿，检查后保存才生效。便携导出不携带本机路径、网页入口、测试目标、快捷键或信任；在新机器上重新配置这些内容。

如果文件在编辑期间被外部修改，保存会停止。点击“重新载入当前配置”会放弃当前草稿并读取磁盘新文件。未来版本配置或无法完整读取的文件受只读保护，不要直接覆盖；修复文件或权限后重新载入。提示“配置已保存，但旧备份暂未清理”表示保存成功，清理会在后续保存时重试。

## 更新与卸载

更新前从托盘退出，并另存一份整个运行数据目录。将新版本完整解压到安装目录；尽量保持程序路径不变。若移动目录，先在原程序关闭自启，再在新位置按需启用。回退程序不等于回退配置或 Windows 系统状态，不要强行覆盖较新 schema。

卸载：先关闭本程序自启，再退出并删除解压目录。运行数据独立保留；确认不再需要后可自行删除上述数据目录。不要删除系统 .NET 运行时来卸载本程序。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示缺少 .NET | Release ZIP 已自带运行时；检查是否完整解压、是否只复制了 EXE，或误用了旧 framework-dependent 包。 |
| 程序入口不能启动 | 在设置中核对并确认该入口；修改路径或参数后需重新确认。 |
| 快捷键冲突 | 更换组合或清空关闭，继续使用托盘。 |
| 配置无法保存 | 看具体提示：冲突用重新载入；只读检查文件版本/权限/大小；不要反复覆盖原文件。 |
| 本机代理可达但目标失败 | 检查目标网址及代理设置；HTTP 状态、端口连接与互联网可用性是不同结果。 |
| 想反馈问题 | 提供版本、RELEASE.json 中提交号、Windows build、操作步骤和相关日志；分享前检查并移除个人路径/网址。 |

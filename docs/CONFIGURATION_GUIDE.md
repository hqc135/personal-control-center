# 配置、迁移与恢复

B4 / 0.4.0。配置格式沿用 schemaVersion=1；新增可选 hotkey，旧配置缺省关闭。结构参考 config.schema.json，业务约束以 ConfigCodec.Validate 为准：256 KiB、20 入口、5 个唯一模块、loopback/端口/安全入口/引用验证。

## 保存与备份

设置页保存只应用外观、模块、代理配置、快捷键期望值及入口列表。不修改音量、电源，不开启唤醒，不启动入口。快捷键保存后尝试注册；冲突会报告，本会话原快捷键仍保留，下一次启动按保存的期望值重试。

config.json 位于 %LOCALAPPDATA%/PersonalControlCenter。写同目录临时文件，flush 后原子替换；保留最近 5 份备份。坏文件保留，启动优先读取可用备份；在设置中选择备份并“读取到草稿”，检查后保存才替换当前文件。高版本配置只读，不能用旧版保存覆盖。

“取消”放弃设置草稿。自启按钮和程序信任确认是独立即时操作，界面有说明，不随取消撤销。

## 便携导入导出

导出保存外观、模块顺序/显示、loopback 地址/端口与系统下载目录入口。去掉全部绝对路径/EXE/网页入口、程序参数、测试目标、代理程序绑定、快捷键、未知扩展字段。不会导出信任、日志、端点 ID 或唤醒状态。网页路径/参数可能含敏感信息，需在接收机重新设置。

导入先按完整配置验证，再生成相同脱敏规则的草稿。既不保存，也不执行系统操作。用户检查并保存才应用；重新添加的 EXE 须核对并取得本机信任。损坏/越界/高版本文件不会替换当前草稿或配置。

便携导出拒绝 config.json、trusted-shortcuts.json、state.json 和 config-* 文件名，防止选错运行配置或备份。建议使用 PersonalControlCenter.portable.json。

## 模块

勾选决定显示，上下移动决定顺序。隐藏音频/电源停止其普通刷新，隐藏代理取消代理检测。隐藏保持唤醒模块不停止已申请的请求；先点击结束，或重新显示模块。全部隐藏时仍可进入设置/退出。

## 快捷键

默认关闭；支持 Ctrl 或 Alt，可加 Shift，搭配单个 A–Z 或 0–9，例如 Ctrl+Alt+P。拒绝 Win、F12、PrintScreen 等。注册使用 MOD_NOREPEAT；先注册新键再清旧键，冲突不丢原键和托盘。退出尝试释放所有已登记 ID，窗口结束后由系统清理。

## 当前用户自启

独立“启用/关闭”按钮，只有点击才访问写接口。只操作 HKCU/Software/Microsoft/Windows/CurrentVersion/Run 的 PersonalControlCenter 值，内容为带引号的当前 EXE 路径加 --tray。默认不写，不提权，不改其他值。

先比较显示时的值与写前回读，变动则拒绝；写后再回读，不把登记等同于 Windows 一定会启动。Windows 启动应用设置可能禁用或延后运行。遇到同名但不同位置/内容的登记，本版拒绝覆盖或删除，避免误删；迁移时先在旧位置应用中关闭自启，再移动到新位置开启。删除程序前先关闭自启。

以上真实文件对话框、热键冲突和自启操作尚未在本机交互验收；自动测试只用临时目录和假平台。
